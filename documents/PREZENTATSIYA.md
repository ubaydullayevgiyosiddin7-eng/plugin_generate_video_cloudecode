# Prezentatsiya: aniq, professional, ishontiradigan slaydlar

YouTube videolaridan saboqlar (2026-11-06; manba va vaqt belgisi har birida). Tavsiya — majburiy emas. Xakaton pitch'i
uchun tuzilish: [`../hackathon/PLAYBOOK.md`](../hackathon/PLAYBOOK.md) §4.

Asosiy fikr: AI slayd toollari chiroyli **ko'rinish** beradi, lekin "nima demoqchimiz" degan **xulosa**ni bermaydi. Ish
uch qatlamga bo'linadi: tadqiqot → hikoya → dizayn. [A 0:00]

## Jarayon (Claude uchun)

```
1. Brief: auditoriya va qaror qiluvchi, vaqt, bitta gaplik asosiy xabar / so'rov, format (pptx yoki HTML).
2. Tadqiqot: faktlar tuzilgan ramka bilan (raqobat, bozor hajmi...) → reytingli xulosa va tavsiya.
3. Hikoya: SCQA (Vaziyat, Murakkablik, Savol, Javob). Pitch uchun: ilgak = vaziyat + murakkablik, demo = javob,
   ta'sir = isbot, oxiri = so'rov.
4. Har slayd: xulosa aytadigan sarlavha + 3 ta dalil (iloji boricha raqam). Taklifda — "nega boshqa variantlar emas"
   slaydi.
5. Sarlavha testi: faqat sarlavhalarni ketma-ket o'qing — butun dalil tushunarli bo'lishi kerak.
6. Dizayn: bitta palitra, bitta sans-serif shrift, grid va bo'sh joy, jadval o'rniga grafik, SVG ikonka yoki haqiqiy
   rasm; AI rasm faqat kontent talab qilsa.
7. Qo'shib emas, qisqartirib: batafsil qoralamadan o'chiriladi, to'ldirilmaydi.
8. Aniqlik tekshiruvi: slaydlar tadqiqot bilan solishtiriladi — yo'qolgan yoki buzilgan fakt tuzatiladi.
9. Render va ko'rik: har slaydda toshib ketish, tekislash, proyektordan o'qilishi. Eksport qilingan faylni ham tekshiring.
10. Spiker eslatmalari va ko'rsatish tartibi, vaqt o'lchab mashq.
```

## Taqdimot qilish (pitch)

- Slaydni o'qimang — tinglovchi siz gapirganingizdan tez o'qiydi. Ekranda kalit fikr, og'zaki — kengaytma. [B 2:40]; [D 5:45]
- Fikrlarni birma-bir oching (animatsiya yoki spotlight). [B 1:51]; [A 11:45]
- Ko'z bilan aloqa: chap, markaz, o'ng; avval do'stona yuzlardan. Ekranga emas, tinglovchiga qarang. [D 6:57], [7:44]
- O'zingizni yozib mashq qiling; 3 daqiqalik pitchni demosi bilan har safar vaqt o'lchab. [D 8:26]
- Rejani vaqt, auditoriya va ular olib ketishi kerak bo'lgan bitta xabardan boshlang. [D 0:28]
- "Muloqotning 55% i tana tili" degan raqamni takrorlamang — Mehrabian tadqiqotining noto'g'ri talqini.

## Tayyor slaydlarni tekshirish

- [ ] Faqat sarlavhalar hikoyani aytadi; har sarlavha — da'vo yoki xulosa
- [ ] Tavsiya / so'rov 1–2-slaydda va oxirgi slaydda
- [ ] Bitta slayd — bitta fikr, ~3 dalil, ≤ 7 qator, paragraf yo'q
- [ ] Har raqamning manbasi bor va tadqiqot bilan mos
- [ ] Ma'lumot — tartiblangan, belgilangan grafik
- [ ] Asosiy matn ≥ 24 pt (bizning chegara), bo'sh joy ko'rinadi, logotip har slaydda takrorlanmaydi
- [ ] Bitta palitra, bitta shrift, ikonkalar bir uslubda
- [ ] Piksellangan, watermarkli, clip-art yoki mazmunsiz bezak rasm yo'q
- [ ] Hammasi gridga tekislangan, eksportdan keyin hech narsa toshmaydi
- [ ] Muqobillar / e'tirozlar yopilgan (taklif uchun)
- [ ] Spiker eslatmalari bor, vaqt o'lchangan mashq slotga sig'adi (pitch: demo bilan 3:00)
